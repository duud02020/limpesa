Como Personalizar Este Site

Este projeto foi construído com arquitetura modular. Todas as configurações da empresa (WhatsApp, telefones, e-mail, lista de serviços e perguntas frequentes) estão centralizadas em um único arquivo:

📁 js/config.js

Passos para personalizar para um cliente real:

  1. Abra js/config.js no seu editor de código.
  2. Altere whatsappRaw para o número com DDD (ex: "5511999990000").
  3. Atualize o nome da empresa, e-mail e horário de atendimento.
  4. Se desejar trocar fotos, substitua os arquivos na pasta assets/images/.
